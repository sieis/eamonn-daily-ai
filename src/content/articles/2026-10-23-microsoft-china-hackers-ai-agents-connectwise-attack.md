keyDetails:
  - "Microsoft attributes the campaign to a group it tracks as Storm-0940, which it describes as China-aligned, and published its findings on October 21"
  - "Reuters reports the group used an AI-driven penetration-testing tool called ARTEX, which can be set to run reconnaissance and data theft on its own"
  - "Over four days ending October 14, the group targeted 327 Microsoft 365 and Exchange Online accounts at eight organizations, then moved on to ConnectWise Cloud Backup customers"
  - "A secondary report says the tool reached more than 2,250 tenants at about 2,900 sign-in attempts per minute. Microsoft saw cases where time from first targeting to privileged access was under three hours"
  - "Most attempts failed, but some succeeded in gaining lasting cloud access. Microsoft stresses that a successful sign-in does not necessarily mean customer data was taken"
  - "ConnectWise said on October 16 it was investigating unauthorized access attempts tied to its Cloud Backup environment. We have not seen Microsoft's original post, so check it for details"
whyItMatters: "Attackers used to need time and skill to break into business accounts. AI tools can now try thousands of logins a minute and move quickly once one works. That means the old advice of fixing a problem when you notice it is no longer enough, because the attack may be over in an afternoon."
consultingAngle: "If your company uses an IT provider or a cloud backup service, ask them three questions this week: Is multi-factor authentication required on every account, including admin and service accounts? Do we get alerts for unusual sign-ins? And how do we revoke access fast if something looks wrong? If you use ConnectWise Cloud Backup, check ConnectWise's guidance. Strong passwords plus MFA stop most of the automated guessing described here."
