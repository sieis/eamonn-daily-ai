keyDetails:
  - "Autopilot: an always-on agent for each user with its own memory, tools and identity. It can follow up on email, watch Teams channels, run recurring work and keep projects moving without being prompted. Coworkers can @mention it in Teams"
  - "Autopilot is rolling out first to Frontier, Microsoft's early-access program. No price or wider release date was given"
  - "Controls: each Autopilot has its own ID and a named human manager. IT can limit what it can reach, shut it off and review a log of its actions, and users can require approval before key actions"
  - "Today: a daily briefing that pulls together mail, calendar, Teams and tasks, flags what needs attention and drafts replies and schedule changes for you to approve. It is in private preview"
  - "Office in Copilot is generally available: Word, Excel and PowerPoint editing inside the Copilot app, included in the Copilot license without extra usage charges"
  - "Copilot Code, arriving in the coming weeks, builds simple apps, dashboards and widgets from a plain-language description and lets you share them like a document"
  - "New cost controls let IT set AI spending limits and alerts. Microsoft also cited a report it commissioned claiming Copilot is much cheaper than Claude and ChatGPT for everyday users, which is a vendor-backed claim"
whyItMatters: "Most AI assistants today wait for you to ask. Microsoft is moving toward assistants that work in the background, like a junior employee who follows up on loose ends without being told. That could save real time, but it also means software acting on your behalf when you aren't watching, which is why Microsoft is stressing logs, approvals and an off switch."
consultingAngle: "If your business runs on Microsoft 365, Office in Copilot is the piece you can use today: drafting and editing documents and spreadsheets from one place. Autopilot and Today are early-access for now, but they are a preview of where every major office suite is headed, with Google and Anthropic building similar always-on agents. Use the waiting time to get ready: tidy up file permissions so an agent can't see what a person shouldn't, decide which actions (sending external email, booking meetings, sharing files) always need a human sign-off, and set an AI spending limit before agents start using credits on their own. Copilot Code is worth a look for simple internal tools like a job tracker or sales dashboard that you'd otherwise build in a spreadsheet."
